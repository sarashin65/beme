# BeME — Beam + IME

LLM と検索技術をフルに使った自作日本語 IME。
転職ポートフォリオとして開発中（2026-08-20 着手）。

## コンセプト

**文脈を読む・ローカルで速い・ランキングで勝負する IME**

- ビームビタビ（K-best Viterbi）による複数候補生成
- 確信度（第1候補と第2候補のコスト差）によるカスケード判定
- 文脈込みの LLM リランク（構想・後段フェーズ）
- 検索のマルチフェーズランキング（retrieve → rerank）を変換パイプラインに応用
