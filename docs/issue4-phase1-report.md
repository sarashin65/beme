# Issue #4 フェーズ1 評価レポート

## 実施概要

`data/corpus.txt`（100 MiB、約 101 万行）を `fugashi`/IPADIC で解析した。頻度集計結果は 7,548,547 tokens、ユニークな `(reading, surface, pos)` は 21,829 件だった。辞書は `data/dictionary.tsv` を直接上書きせず、学習結果を `data/dictionary_learned.tsv` に出力した。

評価はすべて `scripts/evaluate.py` の既定設定（mock reranker、beam width 64、top-k 5）で実行した。

## 常用語の辞書差分

`apply_cost_learning.py` の式 `max(min_cost, old_cost - α * log10(frequency))` により、採用辞書では次の変化があった。

| reading / surface / POS | ベースライン | 学習後 | 備考 |
|---|---:|---:|---|
| `する / する / verb` | 0.800 | 0.100 | 最小コストまで減算 |
| `ある / ある / verb` | 0.800 | 0.100 | 最小コストまで減算 |
| `ある / ある / adnominal` | 2.373 | 1.744 | 頻度に応じて減算 |
| `ある / ある / auxiliary` | 3.587 | 2.629 | 頻度に応じて減算 |
| `わたし / 私 / pronoun` | 1.990 | 1.990 | 対象上位 1,000 語に該当せず変更なし |

AJIMEE の具体例では、`ニテンジタリスルコトハ` がベースラインの「に展示たりする糊塗は」から学習後に「に展示たりすることは」へ改善した。一方、`ワタシ` を含む `ajimee-jwtd-v2-1133` は「私」の表記自体は維持したが、文全体の誤変換は残った。

## 再現手順

採用パラメータ（対象語彙数 1,000、α=0.20）で学習後辞書を再生成するコマンドは次のとおり。`--input` は既存辞書、`--output` は学習後辞書の書き出し先で、`data/dictionary.tsv` は変更されない。

```bash
uv run --group dev python scripts/apply_cost_learning.py \
    --input data/dictionary.tsv \
    --output data/dictionary_learned.tsv \
    --top-n 1000 --alpha 0.20 --workers 4
```
