1. 目的と論理（issue #19 提案アクション 3）

  • Phase 4 の LR は both_correct = 21/64。文脈盲モデルは原理的に 0 しか取れない → 本物の文脈解消は存在する
  • しかし overall +10pt のうち「単語を知っているだけ」の分は未分離だった
  • C0 は文脈を見ない → both_correct は 0 のままのはず。その状態で overall がどれだけ上がるか = 語彙成分の見積り
事前登録の予測: ①C0 の both_correct ≈ 0（0 でなければ測定/実装が壊れている）②C0 の non_contrast_top1 は A8 より上がる。主判定は non_contrast_top1 の gain（issue コメント §5 の指示）。

3. 分離の見積り（§2.4 の形式）

LR の overall gain (Phase 4) : +10.05 pt （.7310 → .8315・参照値・機と日付が異なる） C0 の overall gain (対 A8・同日同機) : +10.55 pt （.7400 → .8455・中央値）← 語彙成分の下限見積り 残差 (X − Y) : -0.50 pt ← 文脈成分 + 交絡の上限見積り（負 = 語彙で説明しきった） C0 の both_correct : 0/64 ← 予測どおり 0（文脈盲の確認）
注記（ミッション制約）: この引き算は上限/下限の粗い見積りであって厳密な分解ではない。L（Phase 4）と C0（task5）は base（A0 vs A8）も学習日も異なる。単一 split の差に p 値は付けない。

4. 解釈

  • 語彙成分が支配的: C0（語彙化・文脈なし）単体で、LR（語彙 + CE 文脈）と同等以上の overall gain（+10.55 vs +10.05・直接比較は不可だが同水準）。Phase 4 の +10pt のほぼ全てが「単語を知っている」ことで説明できる。
  • 文脈の優位は contrast に限定: contrast Top-1 は C0 .4063 vs LR .5313（差 .125 ≈ 文脈の純粋寄与の目安）。真に曖昧な 128 件では CE がまだ勝つ。逆に言えば、overall への文脈の寄与は小さい。
  • issue #19 の仮説がほぼ全域で成立: 「30 パラメータのモデルが持てない語彙知識を CE が肩代わりしているだけの部分があるなら、その部分は語彙化した局所モデルで CE よりずっと安く取れる」→ overall の観点では肩代わり部分が（ほぼ）全体だった。
  • 次の自然な問い: C0 を局所とした LR 版（語彙 + 文脈の併用）は、L ベースの LR よりさらに良くなるか？ contrast の両側を語彙で片付けられる分、CE は真に曖昧なケースに集中できる可能性がある。
