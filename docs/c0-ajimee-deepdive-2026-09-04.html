1.2 解釈

分割誤りが 76→60 件と 21% 減少したのが最大の変化。F2 の語彙知識（コーパス頻度）が「どのトークン境界で区切るべきか」という判断に効いている。典型的には、複合語内部の正しい境界（接尾辞・助動詞の独立）を学習できている。

同音誤りはほとんど変わらない（74→71）。これは予想と整合する — 同音異義語の選択は文脈が決めるべき問題であり、語彙頻度だけでは限界がある（F2 の「頻出表記を優遇」は同音対立の一部に効くが、文脈が要るケースは残る）。

辞書欠落は不変（35 件）。コーパス頻度表は辞書を拡張しないので当然。

CER 寄与は全タイプで減少している。これは誤りが「軽い」ものに変わったことを示す（edit distance の小さい誤りに変わった）。同じ分割誤りでも、C0 では「より正解に近い間違い」を選ぶようになった。

4. 残った課題 — 165 件の still wrong

4.1 まだ残っている分割誤り（60 件）

F2 で改善したが、依然として 接尾辞・助動詞の吸収 が主因。コーパス頻度ではカバーしきれない低頻度の機能語の分割が残っている。これは「接続コストの欠落」問題（旧 deepdive §5）の残滓であり、接続コスト再導入か疎重みで攻めるべき領域。

4.2 同音誤り（71 件）

F2 の効く範囲は限定的。文脈が必要な同音異義語（「複製/復姓」「競技/協議」等）は CE リランカに委ねるのが本道。

4.3 辞書欠落（35 件）

辞書拡張（d1）か、パッチ辺を利用した未知語対応が必要。ただし辞書欠落の CER 寄与は C0 で 262 と減少している（= より軽い誤りになった）。

5. 次の一手への示唆

順項目根拠
1疎な語彙重み（pair + backoff）F2 が効いた領域（分割誤り 21% 減）の延長。単語単位の重みで残りの分割誤りを攻められる。F2（表参照）との比較にもなる
2接続コスト再導入旧 deepdive で最大の律速と特定された問題。IPADIC matrix.def の 16×16 潰しによる情報損失（R²=0.21）をどう補うか
3C0 ベースの LR 実験同音誤りは文脈に委ねるのが効率的。C0 で語彙部分を固めた上で CE の効果を再測定
4#16 打ち直しラティス文脈を探索対象に含める。価値はあるが実装コストと相談

Opus の推奨は「まず #3 を再分析してから決めろ」だった。今回の分析で得られた教訓：F2 は分割誤りに効いたが、同音誤りと辞書欠落には効きが薄い。つまり F2 の次の一手は「疎重みで分割誤りをさらに削る」か「接続コストで根本から攻める」かの二択。C0 ベースの LR 実験はその判断を先送りするだけなので、優先度は下げてよい。
